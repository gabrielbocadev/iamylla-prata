Sobre o material

Por que prata 925?

Todas as peças da Iamylla Prata's são feitas em prata 925 — o padrão mais usado em joalheria fina no mundo todo.

92,5% prata pura

A liga combina 92,5% de prata pura com 7,5% de outros metais, o que dá resistência à peça sem perder o brilho característico da prata.

Feita para o dia a dia

Mais resistente que a prata pura (999), aguenta o uso diário sem perder a forma nem amassar com facilidade.

Fácil de cuidar

Pode escurecer naturalmente com o tempo, mas volta a brilhar com uma limpeza simples usando flanela seca ou produtos neutros.

Salvo neste rascunho — não esqueça de publicar.

Este site é 100% gratuito: os dados ficam num arquivo data.json dentro do seu repositório no GitHub. Toda alteração feita aqui é um rascunho local até você publicar.

  1. Baixe o arquivo data.json atualizado no botão acima.
  2. Abra seu repositório no site do GitHub.
  3. Clique no arquivo data.json existente e depois no ícone de lápis (editar) — ou use "Add file → Upload files" para substituí-lo pelo que você baixou.
  4. Role até o fim da página e clique em Commit changes.
  5. Aguarde 1 a 2 minutos: o GitHub Pages atualiza o site sozinho.
